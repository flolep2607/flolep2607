02 Flagship · core contributor

        
ManifoldBT

        

          Backtesting engine for quantitative research. Strategies in a fluent Python DSL,
          compiled into an optimised Rust expression graph, executed vectorised.
        

        
    
          
  • 500K bars in ~26 ms
    • 
          
  • 161× faster than vectorbt
    • 
          
  • pip install — no Rust toolchain
    • 
        

        

          I wrote effectively all of the next version — engine, DSL surface and validation tooling —
          currently unreleased. Large Rust codebases and adversarial edge-cases are the same
          muscles cybersecurity work uses.
        

        

          Website
          Repository
          PyPI
        

      

      

        

          
          manifoldbt · ema_crossover
        

        
fast, slow = ema(close, 12), ema(close, 26)

strategy = (
    mbt.Strategy.create("ema_crossover")
      .signal("signal", mbt.when(fast > slow, mbt.lit(1.0), mbt.lit(-1.0)))
      .size(mbt.col("signal") * mbt.lit(0.25))
)

result = mbt.run(strategy, config, store)
